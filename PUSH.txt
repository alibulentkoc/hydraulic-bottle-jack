STEP 1  Replace the download folder
--------------------------------------------------------------------------
Delete the old one first, so nothing stale is left behind:

    rmdir /s /q C:\Users\Bulent\Downloads\bottle-jack-lab

Then extract hydraulic-bottle-jack-repo.zip to:

    C:\Users\Bulent\Downloads\bottle-jack-lab

--------------------------------------------------------------------------
STEP 2  Copy over the clone
--------------------------------------------------------------------------
    cd C:\Users\Bulent\Documents\hydraulic-bottle-jack
    git pull
    robocopy "C:\Users\Bulent\Downloads\bottle-jack-lab" "C:\Users\Bulent\Documents\hydraulic-bottle-jack" /E /XD .git
    git status --short

Use robocopy, not drag and drop: four entries start with a dot and Explorer
skips them. Robocopy exits with code 1 on success, which is normal.

These files must appear as new (??). If any is missing, stop and redo step 1:

--------------------------------------------------------------------------
